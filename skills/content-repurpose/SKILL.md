# 多平台内容改写

在保留事实、观点边界与品牌语气的前提下，把同一份原始素材改成用户指定的内容形式。

## 输入与目标

读取原文，提取目标平台或形式、受众、希望读者采取的行动、字数或时长、品牌禁用词与必须保留的信息。

没有原文时请求提供素材；不要以改写之名自行创作事实。目标渠道未指定时，询问渠道或先提供一版通用短文并说明假设，不自行生成大量平台版本。

## 改写流程

1. 建立简短的事实底稿：核心观点、专名、数字及单位、时间范围、适用条件、必要引用。识别素材中尚未经证实的宣传表述。
2. 按目标读者的信息需求重新组织开头、段落和结尾。允许改变表达顺序与篇幅，不改变因果关系或将“可能”改成“必然”。
3. 选择与形式相符的结构：
   - 公众号或博客：完整解释主线，保留必要背景和小标题。
   - 社交笔记：开头交代具体问题或收益，用便于扫描的段落呈现实用信息。
   - 短视频口播：使用短句和自然转场，明确开场、主体与收尾。时长只能估算，必要时建议朗读校准。
   - 专业平台动态：突出观点、依据和讨论问题，避免空泛口号。
4. 标题和开头可以更有吸引力，但不得编造亲身体验、客户证言、销量、排名或保证效果。涉及数字结论时保留样本、时间和条件等重要限制。
5. 只为用户要求的渠道生成内容；行动号召与原文和用户目的相符，不编造链接、优惠或领取方式。

不要把经验性的篇幅建议称为平台硬限制。用户要求满足实时平台规则时，核对官方规则；无法查询则说明未核验，不凭记忆承诺合规。

## 交付与一致性检查

按渠道分别给出标题与正文，口播稿单独标注估算时长。把使用说明放在稿件外。用户只要求成稿时不展示内部事实底稿。

逐项对照各版本的专名、数字、时间、立场与限制条件，修正跨版本矛盾。可省略次要信息，但不能省去会改变读者理解的关键限定。不自动发布到任何平台。
